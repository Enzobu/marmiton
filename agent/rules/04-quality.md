# quality

> Référentiel canonique. Les identifiants sont stables. Appliquer chaque règle lorsqu'elle est pertinente, sauf si une consigne explicite autorisée prévaut.

## Q01 — Architecture

Respecter l'architecture et les frontières existantes.

## Q02 — Séparation

Séparer UI, métier, orchestration et persistance.

## Q03 — DRY raisonné

Factoriser la duplication problématique sans abstraction prématurée.

## Q04 — KISS

Préférer un code simple et explicite.

## Q05 — SOLID contextualisé

Appliquer les principes utiles sans complexifier artificiellement.

## Q06 — Nommage

Utiliser des noms précis et conformes au métier.

## Q07 — Responsabilité

Maintenir des fonctions et classes cohérentes.

## Q08 — Typage

Utiliser les garanties de type disponibles; éviter any et casts aveugles.

## Q09 — Erreurs

Propager, traiter ou journaliser les erreurs de manière intentionnelle.

## Q10 — Code mort

Retirer le code rendu inutile par la modification, sans nettoyage hors périmètre.

## Q11 — Constantes

Nommer les valeurs métier significatives.

## Q12 — Conventions

Conserver style, imports et organisation existants.

## Q13 — Dépendances

Ne pas installer de package sans bénéfice justifié.

## Q14 — Contrats

Préserver interfaces publiques, événements et formats.

## Q15 — Compatibilité

Éviter les ruptures non demandées; documenter les transitions.

## Q16 — Configuration

Externaliser les paramètres variables selon l'environnement.

## Q17 — Ressources

Fermer connexions, fichiers, abonnements et streams.

## Q18 — Effets de bord

Rendre les mutations et dépendances visibles.

## Q19 — Commentaires

Expliquer le pourquoi, non répéter le code.

## Q20 — Commentaires à jour

Mettre à jour les explications affectées par le changement.

## Q21 — Cycles

Éviter les dépendances circulaires entre modules.

## Q22 — Domaine

Respecter la terminologie et les invariants métier.

## Q23 — Taille maîtrisée

Découper les fichiers lorsque la maintenabilité le justifie.

## Q24 — Pas de refonte masquée

Ne pas mélanger corrections mineures et réécriture étendue.
