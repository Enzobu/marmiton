# Analyse visuelle

| Dimension | À examiner |
| --- | --- |
| Densité | Nombre d'éléments visibles, hauteur header/navbar, taille cartes/search |
| Grille | Colonnes, gutters, largeurs, alignements, marges, responsive |
| Typographie | Taille, hauteur de ligne, graisse, hiérarchie |
| Contrôles | Paddings symétriques, selects, flèches, boutons, radios/switches |
| Thèmes | Clair, sombre, système, couleurs sémantiques et contrastes |
| États | Vide, chargement, erreur, succès, focus, hover, disabled |
| Accessibilité | Labels, contraste, navigation clavier, zoom |
| Non-régression | Tous les écrans utilisant les composants modifiés |

## Boucle

1. Observer la référence et l'état courant.
2. Identifier les différences **concrètes** de proportions, espaces et structure.
3. Modifier les tokens ou les composants partagés.
4. Capturer ou voir le résultat réel quand l'outil est accessible.
5. Comparer, corriger, puis valider l'usage fonctionnel.

Ne jamais annoncer « pixel-perfect » sans comparaison réelle. Une image statique ne valide pas les interactions.
